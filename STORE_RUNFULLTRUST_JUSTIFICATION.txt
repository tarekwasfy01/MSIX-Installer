runFullTrust business justification

The application is a compact native C++ desktop utility running with the
interactive user's standard privileges. The user explicitly selects or drops a
local Windows app package. The application signs that selected package with a
user-owned test certificate and installs it for the current user.

The executable manifest uses requestedExecutionLevel="asInvoker". The package
does not declare allowElevation or packageManagement. It does not install
services, drivers, scheduled tasks, or silently modify machine-wide settings.

The signing workflow and signing executable are embedded into the main native
executable. They are extracted only to a unique temporary directory for the
duration of the user-initiated operation and are removed after completion.

Full trust is required because the product is a native Win32 C++ application
that must access the file explicitly selected by the user and invoke the local
Windows package signing and deployment workflow.
