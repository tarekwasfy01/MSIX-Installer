Everything in one project

A practical workflow for Windows application packaging

Define the important installer settings in a compact project file, open it in Setup Studio and build the setup package from the same interface.

01

Readable project files

Store the configuration in a plain-text .csetup file that is easy to review, edit and keep together with your project.

02

Application metadata

Configure the application name, version, identifier, publisher, description, website and support address.

03

Installation layout

Choose the source directory, main executable, default installation directory, installation folder and output path.

04

Shortcut options

Control desktop shortcuts, uninstall support and whether users may change the target directory or selected components.

05

Architecture targets

Declare target architectures such as x64, ARM64 and x86 directly in the project configuration.

06

Integrated build output

Start the build from Setup Studio and follow status messages in the dedicated output panel.

Simple. Fast. Native.

From application folder to setup package

Setup Studio keeps the process transparent. Your payload remains in a normal folder and the project file describes how the installer should be built.

  1. 1

    Prepare the payload

    Place the application executable and all required files in the source directory.

  2. 2

    Configure the project

    Set metadata, paths, architecture targets, shortcuts and installer behavior.

  3. 3

    Build and review

    Run the build, inspect the output and distribute the generated setup package.

A project format you can understand at a glance

Paths are relative to the project file, which makes the project folder easy to move, archive or maintain in version control.

App metadata Source directory Main executable Install path Architectures Compression Shortcuts Uninstaller
MyApplication.csetup 
; Setup Studio project
; Paths are relative to this .csetup file.

[Setup]
AppName=My Application
AppVersion=1.0.0
AppId=MyCompany.MyApplication
Publisher=My Company
Description=A native Windows application
Website=https://example.com
SupportUrl=https://example.com/support
SourceDir=payload
MainExe=MyApplication.exe
Output=dist\MyApplication-Setup.exe
InstallScope=user
DefaultDir={localappdata}\Programs\My Application
InstallFolder=My Application
Architectures=x64,arm64,x86
MinWindowsBuild=19041
Compression=lzms
AllowDirectoryChange=true
AllowComponentChange=true
CreateUninstaller=true
DesktopShortcut=true
